# OWS Base Wallet Tracker - AI-Powered Analysis

This project is a secure, AI-powered wallet analysis tool built on the Base blockchain using the Open Wallet Standard (OWS).

## 🚀 Features
- **OWS Security**: The AI agent never accesses the wallet’s private key. It operates with read-only permissions.
- **Blockchain Analysis**: Retrieves the latest transactions for any wallet on the Base chain.
- **AI Insights**: Analyzes transaction history to provide reports on wallet behavior, risk scores, and patterns.
- **Simple Interface**: User-friendly web dashboard.

## 🛠️ Setup and Execution
1.  Install the required tools: `Node.js`
2.  Clone the project: `git clone https://github.com/homodeus042/ows-wallet-tracker.git`
3.  Install dependencies: `npm install`
4.  Copy the `.env.example` file to `.env` and add your own API keys (Basescan, Anthropic, OWS) to it.
5.  Start the server: `npm start`
6.  Go to `http://localhost:3000` in your browser.
